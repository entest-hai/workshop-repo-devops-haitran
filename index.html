Building a DevOps CI/CD Pipeline on AWS

From a push on GitHub to a live container on Amazon ECS — automated build, image publishing, and blue/green deployment with AWS CodePipeline, CodeBuild, and CodeDeploy.

Pipeline Architecture

Code committed to GitHub triggers a three-stage pipeline. CodeBuild packages a Docker image into Amazon ECR, then CodeDeploy rolls out a new version to the ECS cluster.

Source (GitHub) Build (CodeBuild) Deploy (CodeDeploy) Image registry (ECR) Runtime (ECS)

Key Terms (quick reference)

Short definitions for the services on this page.

CodePipelineOrchestrator that wires the stages together and runs them on every code change.
CodeBuildManaged build service — runs buildspec.yml to compile code and build the Docker image.
CodeDeployAutomates releasing the new version to ECS using a blue/green strategy (safe rollback).
Amazon ECRPrivate Docker image registry where CodeBuild pushes the container image.
Amazon ECSContainer runtime that runs your application as tasks/services.
Blue/GreenRun old (blue) and new (green) versions side by side, shift traffic, roll back instantly if needed.
